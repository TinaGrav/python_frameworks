# Лабораторные работы по фреймворкам Python для анализа данных

Каждая лабораторная работа рассчитана на отработку навыков в области анализа данных. 

[Лабораторная 1](https://github.com/TinaGrav/python_frameworks/tree/lab1) - освоение базового ML-пайплайна на табличных данных. В работе произведен разведочный анализ данных с использованием визуализации, выполнена предобработка: обработка пропусков, коррекция выбросов, кодирование категориальных признаков, масштабирование, отобраны релевантные признаки. Произведено обучение Linear Regression для задачи регрессии (спрогнозирована CGPA успеваемость студента на основе его режима занятий и сна), обучение Logistic Regression для задачи классификации (определено, подвержен ли учащийся риску развития депрессии (столбец Depression), исходя из его образа жизни и уровня стресса). Оценено качество моделей с использованием соответствующих метрик.

[Лабораторная 2](https://github.com/TinaGrav/python_frameworks/tree/lab2) - временные ряды. Произведена очистка и унификация данных: приведение к единому временному индексу, обработаны пропуски и выбросы. Произведен анализ временного ряда: визуализация, проверка стационарности, декомпозиция на тренд, сезонность и остатки, спектральный анализ, из временного ряда извлечены признаки, полезные для прогнозирования. Построено дерево решений, случайный лес и бустинг. Подобраны гиперпараметры через optuna, использованна рекурсивная стратегию и стратегия создания модели на каждый из горизонтов. Качество прогноза оценено на тестовом отрезке с использованием метрик. 

[Лабораторная 3](https://github.com/TinaGrav/python_frameworks/tree/lab3) - изображения и видео. Выполнено декодирование исходного видеоролика в последовательность кадров. Использован публичный компьютерно-зрительный API для получения координат bounding box’ов на каждом кадре. Были опробованы несколько методов нахождения bbox и предоставлен их сравнительный анализ. Оценено качество извлеченной разметки сравнивая с оригиналом по IoU. Сформирован структурированный датасет с аннотациями в одном из стандартных форматов: COCO. Обучен детектор объектов на основе готовой архитектуры из torchvision.models.detection. Оценено качество модели с использованием метрики mAP (mean Average Precision) на валидационной выборке.
